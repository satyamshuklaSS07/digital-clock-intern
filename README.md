# Digital Clock

## Description
A live digital clock that displays the current hours, minutes, and seconds, updating automatically every second.

## Objective
Practice JavaScript Date objects, timers, DOM selection, and DOM updates.

## Tools
- HTML5
- CSS3
- JavaScript

## Deliverables
- A live digital clock showing HH:MM:SS
- Automatic updates every second
- Simple responsive styling

## Approach
- Used the `Date` object to get the current time.
- Used `setInterval` to update the display every second.
- Added leading zeros to single-digit values using a helper function.
- Styled the clock with a responsive, centered layout using CSS3.
